# Сорока

[English](README.md) · **Українська**

Сорока — застосунок у треї Windows для Microsoft Teams (робочі або навчальні облікові записи). Teams працює у вікні Сороки як веб-сторінка, і це вікно може бути прихованим. Особисті повідомлення, @згадки й дзвінки приходять маленькими картками в кутку екрана. З картки можна відповісти, поставити реакцію або отримати підсумок, не відкриваючи Teams.

Відповіді й підсумки може писати ШІ з підписки, за яку ви вже платите: Claude Code, Codex (ChatGPT), Gemini CLI та інші. Жодних API-ключів і додаткових рахунків. Без вашого кліку нічого не надсилається.

> Сорока — незалежний проєкт. Він не пов'язаний із Microsoft, не схвалений і не підтримується нею. Застосунок працює з веб-версією Teams такою, як вона виглядає зараз, тож оновлення Teams може зламати частину функцій, доки не вийде оновлення Сороки.

## Можливості

**Сповіщення**
- Картки на особисті повідомлення, @згадки й ключові слова, також у групових чатах. Згадки в каналах беруться зі стрічки «Активність» Teams.
- Фільтри «Лише від», «Не сповіщати від» і тихі години. Те, що прийшло в тихі години, Сорока покаже, щойно вони скінчаться.
- Нагадування. Повідомлення без відповіді повертається через заданий час, а ваше запитання, на яке не відповіли, можна нагадати одним кліком.
- За бажанням ШІ відбирає вхідні. Те, що чекає на вас, приходить одразу, решта — однією карткою раз на годину.

**Відповідь із картки**
- Відповідь просто в картці. На картці є готові фрази та швидкі реакції Teams 👍 ❤️ 😆, повний набір реакцій Teams — у її меню ⋯.
- ✨ просить у ШІ варіанти відповіді, повторне натискання показує наступний. Напишіть перед ✨, що має бути у відповіді («ввічливо відмов, зроблю завтра»), і кожен варіант складеться за цим.
- Панель «Відповіді» поруч із Teams тримає всі картки в одному місці. Картку можна відкласти (30 хв, 1 год, 3 год, завтра) або надіслати з цитатою.
- «Покращити текст» переписує те, що ви набрали в Teams: виправлено, коротше, ввічливіше або перекладом.
- Повідомлення, написані ШІ, можуть мати позначку 🤖. Ваші власні слова її не отримують.

**Підсумки**
- Підсумок одного чату за вибраний період, кількох чатів разом, «Що я пропустив» або дайджест дня. Також можна поставити запитання про чат замість підсумку.
- «Вибірка без ШІ» працює без жодного ШІ: що чекає на вас, задачі, посилання, файли, дати й хто писав.

**Дзвінки**
- Вхідний дзвінок або нарада, що почалася, — картка вгорі праворуч із кнопками самого Teams.
- Дзвінок відкривається в окремому вікні, як у застосунку Teams. Для демонстрації екрана є вибір екрана чи вікна.

**Jira** (Server / Data Center)
- Біля ключів і посилань на задачі в чатах і картках видно статус і назву задачі.
- Персональний токен зберігається зашифрованим засобами Windows (DPAPI) і надсилається лише в ту Jira, для якої його збережено.

**Зручності**
- Інтерфейс українською, англійською та російською. Коли ви обираєте мову чи тему Сороки, Teams теж перемикається, один раз; подальша зміна в самому Teams лишається вашою.
- Гарячі клавіші у вікні Teams: Ctrl+Shift+R — варіанти відповіді, Ctrl+Shift+S — підсумок, Ctrl+Shift+I — покращити текст, F5 — перезавантажити Teams.
- Коли вікно приховане, Сорока віддає пам'ять Windows (близько 250 МБ замість 1,5 ГБ).

## ШІ: ваша підписка, без API-ключів

Сорока знаходить програми ШІ, встановлені на комп'ютері, і працює з підпискою, у яку в них виконано вхід:

| Програма | Підписка |
|---|---|
| Claude Code (зокрема вбудований у Claude Desktop) | Claude |
| Codex CLI | ChatGPT |
| Gemini CLI | Google |
| GitHub Copilot CLI | GitHub Copilot |
| Cursor CLI (`cursor-agent`) | Cursor |
| Antigravity | Google |
| Ollama | без підписки, працює на вашому комп'ютері |

«Оновити» в Налаштування → ШІ питає кожну програму, які моделі є у вашій підписці. Ви обираєте модель для відповідей і модель для підсумків. Якщо в моделі вичерпано ліміт, відповідає наступна готова.

Перевірено наживо: Claude Code і Codex. Решта — за їхньою документацією.

Без ШІ Сорока так само сповіщає, дає відповідати вручну й робить вибірку без ШІ. «Не використовувати ШІ» в налаштуваннях вимикає ШІ повністю.

## Приватність і безпека

- **Без вашого кліку нічого не надсилається.** Це стосується карток, панелі й запитів від сесій ШІ на вашому комп'ютері (див. локальний API нижче).
- **Куди йде листування.** Текст чату потрапляє лише до того ШІ, чию модель ви обрали, за умовами вашої підписки. Ollama лишає його на вашому комп'ютері. Безкоштовні тарифи можуть навчатися на отриманих даних, тож для робочих чатів беріть робочу підписку.
- **«Не в ШІ».** Чати й люди з цього списку ніколи не потрапляють до ШІ. Їхні повідомлення вирізаються й із переписки в інших чатах.
- **Фоновий ШІ — без інструментів.** Те, що Сорока питає в ШІ сама (варіанти відповіді, підготовлені наперед для нових повідомлень, відбір ШІ, дайджест дня), іде лише до ШІ без інструментів: Claude, Codex із вимкненими інструментами або Ollama. Повідомлення в чаті не може змусити ШІ запустити команду, прочитати файл чи відкрити сайт.
- **Ваші дані лишаються на комп'ютері.** Сеанс Teams, налаштування й токен локального API зберігаються в `%APPDATA%\Soroka`. Власного сервера в Сороки немає, телеметрії вона не надсилає.
- **Локальний API — лише локальний.** Він слухає `127.0.0.1`, вимагає токен і відхиляє запити зі сторінок у браузері.

## Вимоги

- Windows 10 або 11, x64. Інші системи не перевірялися.
- Обліковий запис Microsoft Teams для роботи чи навчання.
- За бажанням — одна з програм ШІ з таблиці вище, у якій виконано вхід у підписку.

## Встановлення

1. Завантажте `Soroka Setup <версія>.exe` зі сторінки Releases або зберіть його з коду (нижче).
2. Запустіть. Сорока встановлюється для поточного користувача, без прав адміністратора. Інсталятор не підписаний, тож Windows SmartScreen може попередити: оберіть «Докладніше» → «Усе одно запустити».
3. Увійдіть у Teams у вікні, що відкриється. Далі Сорока живе в треї. Налаштування відкриваються з іконки в треї або кнопкою ⚙ у заголовку вікна.

## Збірка з коду

```bash
npm ci
npm start          # запуск із коду
npm run dist       # збірка release/Soroka Setup <версія>.exe
```

`release/Soroka Setup <версія>.exe /S` встановлює без запитань.

Якщо запускаєте з термінала всередині VS Code, спершу приберіть змінну `ELECTRON_RUN_AS_NODE`. VS Code її задає, і з нею Electron стартує як звичайний Node.

## Локальний API для сесій ШІ

Сорока відкриває API на `127.0.0.1:8765` для сесій ШІ на вашому комп'ютері, наприклад Claude Code. Кожен запит містить заголовок `x-token`; токен лежить у `%APPDATA%\Soroka\token.txt`. Обгортка — `tb.mjs`:

```bash
node tb.mjs chats                         # список чатів: * непрочитане, @ згадка
node tb.mjs unread                        # непрочитані особисті чати й згадки
node tb.mjs read "<чат>" [n]              # останні n повідомлень
node tb.mjs summary "<чат>" [n] [plain]   # підсумок; plain — без ШІ
node tb.mjs draft "<чат>" "<текст>"       # картка вам на затвердження
node tb.mjs send "<чат>" "<текст>"        # іде після вашого кліку «Надіслати» в картці
node tb.mjs gifs "<запит>"                # пошук GIF, нічого не надсилає
node tb.mjs notify "<заголовок>" "<текст>" # картка з повідомленням для вас
```

## Як це працює

Сорока — застосунок на Electron, написаний на TypeScript. Teams працює як веб-сторінка у вікні Сороки. Сорока читає список чатів і повідомлення з цієї сторінки, а друкує й клацає в ній через протокол Chrome DevTools, тож усе працює й тоді, коли вікно приховане. Спостерігач у сторінці одразу повідомляє про нові повідомлення.

Програми ШІ працюють окремими процесами. Текст чату потрапляє до них через стандартний вхід або аргументом лише тоді, коли командна оболонка не задіяна, тож повідомлення не може підкинути команду.
